## 五、已知问题和注意事项

### 5.1 report_exporter.py section_num Bug

**位置**：`observer_core/audit/report_exporter.py` 第 146-173 行

**问题**：`section_num` 变量仅在 `if agent_summaries:` 块内定义（第 146 行），但在块外的"跨 Agent 关联"（第 164 行）和"事件处理时间线"（第 173 行）中被引用。当场景无 agent_summaries 时，会触发 `UnboundLocalError`。

**影响**：低。当前由 `main.py` 的 try-except 兜底，不会导致程序崩溃，但可能导致部分报告内容缺失。

**规避方式**：在 report_exporter.py 第 144 行之前添加 `section_num = 3`（默认值）。

> **注意**：由于零改动约束，此 bug 未在本次修复。Windows 端如需修复，请自行解除约束后修改。

### 5.2 C++ ↔ Python 管道端到端重连

**状态**：Linux 端未验证（C++ probe 仅在 Windows 编译）。

**待验证内容**：
- C++ probe 通过 Named Pipe 发送事件到 Python pipe_reader
- 管道断开后 C++ probe 自动重连
- 重连后事件流无丢失

**对应测试**：`tests/test_pipe_communication.py`（26 个单元测试已通过，但端到端集成需 C++ probe 配合）。

### 5.3 conftest.py 权限混合运行

**现象**：先用 `sudo` 运行测试后，再用普通用户运行可能出现 PermissionError。

**已修复**：conftest.py 已添加 chmod 重试 + `/tmp/` 回退逻辑。但如果 output/ 目录被 root 完全锁定，部分写入可能仍失败（不影响测试结果本身，仅影响 JSON 报告输出位置）。
