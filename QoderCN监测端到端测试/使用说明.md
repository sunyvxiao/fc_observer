# Qoder CN 监测端到端测试 — 使用说明

> 版本: 1.0 ｜ 配套: `QoderCN监测端到端测试用例.md`（用例定义）、`run_e2e.py`（自动化脚本）
> 适用读者: 测试执行者 / 验收者；无需了解项目内部实现即可按本文执行

---

## 1. 环境要求

| 项 | 要求 | 检查命令 |
|---|---|---|
| Python | 3.10+（项目同版本） | `python --version` |
| mcp 包 | 已安装（daemon 传输依赖） | `python -c "import mcp"` |
| 端口 | `config.yaml` `mcp_report.port`（默认 8765）空闲 | `ss -ltn \| grep 8765` |
| 工作目录 | 无要求（脚本自动定位项目根） | — |

模拟注入方式**不真实执行任何危险命令**，可在开发机直接运行；仅真实 Qoder CN 会话用例（E 组）需要隔离环境。

## 2. 一键运行（推荐）

```bash
cd <项目根>                       # 含 observer_sim/ 的目录
python QoderCN监测端到端测试/run_e2e.py            # 标准输出结果表
python QoderCN监测端到端测试/run_e2e.py --verbose  # 附加 start/stop 返回与审计计数细节
```

脚本自动完成五步：**启动监测 → 注入 11 条用例 → 优雅停止（生成报告）→ 审计核验（覆盖率/字段/逐用例判定）→ 产物核验**，全程约 40~60 秒。

**输出**：
- stdout：逐用例 ✅/❌ 结果表 + 覆盖率/字段完整性/产物核验 + 汇总行
- `e2e_result_<时间戳>.json`：机器可读结果（含每用例期望/实际判定、规则、风险分）

**退出码**：`0` 全部通过 ｜ `1` 存在失败用例或核验不通过 ｜ `2` 环境问题（无法启停监测）

## 3. 手工单用例调试

```bash
cd <项目根>/observer_sim

# 1) 启动
python -c "import qoder_report_gateway as g; print(g.start())"

# 2) 注入单条（示例: rm -rf /）
python -c "import qoder_report_gateway as g; print(g.simulate('run_in_terminal', {'command': 'rm -rf /'}, session_id='debug-1'))"

# 3) 观察（三选一）
curl -s "http://127.0.0.1:8080/api/qoder-monitor/events?tail=10" | python -m json.tool   # 需先起 Web 服务
curl -N "http://127.0.0.1:8080/api/qoder-monitor/events/stream"                          # SSE 实时流
python -c "import qoder_report_gateway as g; [print(e) for e in g.get_events()['events']]"  # 直读网关

# 4) 停止并生成报告
python -c "import qoder_report_gateway as g; print(g.stop())"
```

Web 途径：`python app.py` → "📡 Qoder CN 监测"视图 → 启动监测 / 模拟注入表单 / 实时事件流（SSE）。
控制台途径：`python observer.py menu` → Qoder CN 域 → start / sim / events / stream / stop。

## 4. 产物位置与核验点

```
observer_sim/output/qoder_monitoring/
├── audit/audit_mcp_report_<日期>.jsonl   ← 审计（D-1 覆盖率、D-2 字段、逐用例判定）
├── reports/risk_report_*.md              ← 风险报告（判定明细、规则、阻断/告警清单）
└── monitoring_summary.json               ← 汇总（total_events / allow/alert/block / 规则分布）
```

也可通过文件管理查看：Web "文件管理 → 📡 Qoder CN 监测"标签，或 `python observer.py files tree`。

## 5. 结果解读

| 现象 | 含义 | 处理 |
|---|---|---|
| 用例 ❌ 且标注"漏报" | 审计中找不到该事件 | 检查注入是否 accepted；再查 qoder.yaml 映射（见差距清单） |
| 用例 ❌ 判定/规则不符 | 规则未命中或误报 | 对照用例文档第 1.3 节规则速查，记入差距清单 |
| 覆盖率注入≠审计 | 通道丢失/重复 | 检查 daemon 日志 `.monitoring/qoder_daemon.log` |
| 退出码 2 | daemon 未就绪 | 端口冲突或依赖缺失；`--verbose` 查看日志尾部提示 |

## 6. 清理

- 脚本正常结束会停止 daemon；异常中断时手动清理：
  `python -c "import qoder_report_gateway as g; g.stop()"`
- 历史结果文件（`e2e_result_*.json`）可按需删除，不影响系统。
