## 3. 规则配置

| 字段 | 配置值 |
|---|---|
| 规则来源（hook 侧） | config.yaml `hook.protected_paths × hook.protected_extensions`（D-2 唯一基准，改规则只改配置） |
| 规则来源（监测侧） | default_policy.yaml：R007b（block：.env/credentials/*_key/*.pem/id_rsa 等 16 模式）、R007（alert：*secret*/*token*/*password* 等）、R011（block：SSH 基础设施） |
| 危险等级 | hook 侧：受保护命中即 deny；监测侧：block（R007b/R011）/ alert（R007） |
| 处理方式 | hook 侧 deny：工具不执行（exit 2）；监测侧 BLOCK：MockCommandSender 仅留痕不执行 |
| 适用工具 | hook 侧：Read/Write/Edit/Glob 实测触发；监测侧：file_read 事件（申报流） |
| 说明 | 与参照报告「任意路径文件名正则」口径不同：本项目为「目录×扩展名」双重锚定；.env 仅在加入扩展名清单且位于受保护目录内时被拦 |

### 3.1 匹配口径

- **hook 侧**：`extract_target` 提取 file_path → 路径位于 protected_paths 内 **且** 扩展名在 protected_extensions 内 → deny；其余一律放行（fail-open）。
- **监测侧**：R007b 文件名模式（*.env、*credentials*、id_rsa 等）命中 BLOCK 留痕；R011 命中 .ssh 等 SSH 基础设施路径。

### 3.2 触发逻辑

1. WorkBuddy 调用 Read → PreToolUse hook → hook_gate 判定 → deny（exit 2 + stderr）或放行（exit 0 静默）。
2. deny 时：工具不执行；hook_decisions.jsonl 留痕；WorkBuddy 若申报该读取 → 判定管线 R007b/R011 命中 → audit 留痕。
3. 放行时：工具正常执行；若有申报 → 判定留痕（对照组成对验证）。
