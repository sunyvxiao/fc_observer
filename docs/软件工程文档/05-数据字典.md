## 二、输入数据

### 2.1 测试用例定义（YAML 场景文件）

- **来源**：`scenarios/{normal,anomalous,boundary,multi_agent,extreme}/*.yaml`（37 个文件）
- **格式**：YAML 1.2
- **用途**：定义模拟 Agent 行为序列，驱动 SimulationCollector 生成 RawEvent 序列
- **消费方**：`SimulationCollector`

**顶层结构**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| `scenario_id` | string | ✅ | 场景唯一标识，如 `n01`、`a07` |
| `name` | string | ✅ | 场景名称，如 "标准代码开发流程" |
| `category` | string | ✅ | 分类：`normal` / `anomalous` / `boundary` / `multi_agent` / `extreme` |
| `description` | string | ❌ | 场景描述 |
| `expected_result` | string | ❌ | 预期结果说明 |
| `agents` | list[Agent] | ✅ | 参与场景的 Agent 列表 |
| `events` | list[EventDef] | ✅ | 事件序列定义 |

**Agent 定义**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `agent_id` | string | Agent 唯一标识，如 `developer-01` |
| `framework` | string | Agent 框架，如 `LangChain`、`AutoGen`、`Dify` |

**EventDef 定义**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| `event_id` | string | ✅ | 事件唯一标识 |
| `type` | string | ✅ | 事件类型：`exec` / `file_open` / `net_conn` |
| `agent_id` | string | ✅ | 关联 Agent |
| `delay_ms` | int | ✅ | 距上一事件的延迟（虚拟时钟毫秒） |
| `executable` | string | exec 必填 | 可执行文件路径 |
| `arguments` | list[str] | ❌ | 命令参数列表 |
| `file_path` | string | file_open 必填 | 文件路径 |
| `file_op` | string | ❌ | 文件操作：`read` / `write` / `delete` / `rename` / `chmod` |
| `remote_addr` | string | net_conn 必填 | 远程 IP 地址 |
| `remote_port` | int | ❌ | 远程端口 |
| `protocol` | string | ❌ | 协议：`TCP` / `UDP` |
| `description` | string | ❌ | 事件描述 |

**示例**（片段）：
```yaml
scenario_id: a01
name: "高危系统命令：rm -rf /"
category: anomalous
agents:
  - agent_id: "attacker-01"
    framework: "LangChain"
events:
  - event_id: "evt001"
    type: exec
    agent_id: "attacker-01"
    delay_ms: 100
    executable: "/usr/bin/rm"
    arguments: ["-rf", "/"]
    description: "尝试删除根目录"
```

### 2.2 Agent 行为事件（RawEvent）

- **来源**：ICollector 实现（6 种采集模式）
- **格式**：Python `dataclass`（内存）+ JSON 行（管道传输/文件存储）
- **定义文件**：`models/event.py` → `RawEvent`
- **用途**：系统核心处理对象，贯穿整个 Pipeline

**字段定义**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| `event_id` | string | ✅ | 事件唯一标识 |
| `timestamp_ns` | int | ✅ | 纳秒时间戳（虚拟/真实时钟） |
| `event_type` | string | ✅ | 事件类型枚举：`exec` / `file_open` / `net_conn` |
| `pid` | int | ✅ | 进程 ID |
| `ppid` | int | ✅ | 父进程 ID |
| `agent_id` | string | ✅ | 关联 Agent 标识 |
| `agent_framework` | string | ✅ | Agent 框架名称 |
| `executable` | string | exec | 可执行文件路径 |
| `arguments` | list[str] | exec | 命令参数 |
| `file_path` | string | file_open | 文件路径 |
| `file_op` | string | file_open | 文件操作类型 |
| `remote_addr` | string | net_conn | 远程 IP 地址 |
| `remote_port` | int | net_conn | 远程端口 |
| `protocol` | string | net_conn | 网络协议 |

**JSON 序列化示例**：
```json
{
  "event_id": "evt001",
  "timestamp_ns": 1718092800100000000,
  "event_type": "exec",
  "pid": 10001,
  "ppid": 10000,
  "agent_id": "attacker-01",
  "agent_framework": "LangChain",
  "executable": "/usr/bin/rm",
  "arguments": ["-rf", "/"],
  "file_path": null,
  "file_op": null,
  "remote_addr": null,
  "remote_port": null,
  "protocol": null
}
```

### 2.3 安全策略规则（YAML 规则文件）

- **来源**：`rules/default_policy.yaml`（v2.0，21 条规则）
- **格式**：YAML 1.2
- **用途**：RuleEngine 加载并执行规则匹配
- **消费方**：`RuleEngine.load_rules()`

**顶层结构**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `version` | string | 规则版本号，当前 `"2.0"` |
| `metadata` | dict | 元数据（创建时间、更新说明等） |
| `rules` | list[PolicyRule] | 规则列表 |

**PolicyRule 字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `rule_id` | string | 规则唯一 ID，如 `R001` |
| `name` | string | 规则名称 |
| `category` | string | 规则类别：`command` / `file` / `network` |
| `priority` | int | 优先级 0-100，越高越优先 |
| `enabled` | bool | 是否启用 |
| `action` | string | `block` / `alert` / `allow` |
| `description` | string | 规则描述 |
| `conditions.event_type` | string | 匹配事件类型 |
| `conditions.match_mode` | string | 匹配模式：`pattern` / `exact` / `regex` / `path_glob` |
| `conditions.patterns` | list[str] | 匹配模式列表 |

**当前规则分布**：
| 类别 | 数量 | ID 范围 |
|------|:---:|------|
| command（命令执行） | 9 | R001-R006, R016-R018 |
| file（文件操作） | 7 | R007, R007b, R008-R011, R019 |
| network（网络连接） | 5 | R012-R015, R020 |

### 2.4 全局配置（config.yaml）

- **来源**：`config.yaml`
- **格式**：YAML 1.2
- **用途**：全局参数配置，被所有子系统读取
- **消费方**：main.py / demo.py / app.py，以及各 `observer_core/` 模块

**主要配置段**：

| 配置段 | 说明 | 关键参数 |
|--------|------|---------|
| `mode` | 运行模式 | `auto` / `simulation` / `strace` / `ebpf` / `file_replay` / `deep_agent` |
| `pipeline` | 跨平台管道配置 | win_event_pipe, linux_event_fifo, linux_command_fifo |
| `simulation` | 模拟模式参数 | scenarios_dir, cpp_probe_exe, step_by_step |
| `ebpf` | eBPF 模式参数 | bpf_object_path, target_pid, perf_buffer_page_count |
| `strace` | strace 模式参数 | strace_bin, trace_syscalls |
| `file_replay` | 回放模式参数 | data_file, loop, time_scale |
| `deep_agent` | DeepAgent 参数 | mode, scenarios_dir, task, duration_s |
| `scoring` | 评分权重 | dimensions.rule_match.weight=0.40 等 |
| `blocking` | 阻断升级阈值 | violation_window_ms, tier1_to_tier2_threshold=5 |
| `monitoring` | 监测窗口 | event_window_size=10, process_window_ms |
| `baseline` | 基线参数 | min_events_for_baseline=20 |
| `output` | 输出目录 | audit_dir, reports_dir, graphs_dir, baselines_dir |
| `scenarios` | 场景文件列表 | 37 个 YAML 场景路径 |

## 三、中间/可复用数据

### 3.1 录制文件（EventRecorder 输出 / FileReplayCollector 输入）

- **来源**：`collector/event_recorder.py` 写入；可作为 `FileReplayCollector` 回放输入
- **格式**：JSONL（每行一个 RawEvent JSON 对象）
- **用途**：录制 Agent 行为，支持"录制→回放"闭环；白盒测试数据源
- **可复用性**：既是 Agent 行为的输出记录，又可作为回放模式的输入

**记录格式**（每行）：
```json
{"event_id":"evt001","timestamp_ns":1718092800100000000,"event_type":"exec","pid":10001,"ppid":10000,"agent_id":"agent-01","agent_framework":"LangChain","executable":"/usr/bin/git","arguments":["clone","https://..."],"file_path":null,"file_op":null,"remote_addr":null,"remote_port":null,"protocol":null}
```

---

### 3.2 基线快照（BaselineChecker 输出 / RiskScorer 输入）

- **来源**：`BaselineChecker.save_baseline()` 写入
- **格式**：JSON（单文件）
- **存储路径**：`output/baselines/baseline_{timestamp}.json`
- **用途**：跨场景复用——场景 1（正常行为）构建基线，场景 2+（异常/边界）加载基线，启用偏离检测

**BaselineModel 字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `command_freq` | dict[str, int] | 命令频率分布 |
| `file_path_prefixes` | list[str] | 常见文件路径前缀集合 |
| `net_targets` | list[str] | 常见网络目标集合 |
| `event_type_freq` | dict[str, int] | 事件类型频率分布 |
| `agent_profiles` | dict[str, dict] | 各 Agent 行为画像 |
| `total_events` | int | 已收集事件总数 |
| `is_warm` | bool | 基线是否已预热 |

---

### 3.3 行为图谱（BehaviorGraph 输出）

- **来源**：`observer_core/audit/behavior_graph.py`
- **格式**：JSON（结构化图数据）
- **存储路径**：`output/graphs/behavior_{scenario_id}_{timestamp}.json`
- **用途**：记录 Agent 间的事件关系和跨 Agent 数据流，供后续图分析

**图结构字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `nodes` | list[dict] | 事件节点（event_id, agent_id, event_type 等） |
| `edges` | list[dict] | 节点间关系边（source_id, target_id, edge_type, description） |
| `agent_summaries` | dict[str, dict] | 各 Agent 行为统计摘要 |

### 3.4 归一化事件（NormalizedEvent）- 内存中间数据

- **定义文件**：`models/event.py` → `NormalizedEvent`
- **格式**：Python dataclass（仅内存，不持久化）
- **用途**：Pipeline 内部传递的核心数据结构

**字段**（继承自 RawEvent）：

| 新增字段 | 类型 | 说明 |
|---------|------|------|
| `raw` | RawEvent | 原始事件引用 |
| `agent_context` | AgentContext | Agent 运行时上下文（进程列表、滑动窗口） |
| `process_node` | ProcessNode | 进程树节点 |
| `command_string` | string | exec 事件的完整命令拼接 |
| `is_blocked` | bool | 是否已被阻断 |
| `block_reason` | string | 阻断原因 |

---

### 3.5 Agent 上下文（AgentContext）- 内存中间数据

- **定义文件**：`models/event.py` → `AgentContext`
- **用途**：跟踪单个 Agent 的完整运行状态

**字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `agent_id` | string | Agent 唯一标识 |
| `framework` | string | Agent 框架名称 |
| `pids` | list[int] | 关联的所有进程 PID |
| `event_count` | int | 已处理事件总数 |
| `recent_events` | list[NormalizedEvent] | 最近 N 个事件（滑动窗口，默认 10） |
| `max_recent` | int | 滑动窗口大小 |

---

### 3.6 进程树节点（ProcessNode）- 内存中间数据

- **定义文件**：`models/event.py` → `ProcessNode`
- **用途**：维护 pid→ppid→agent_id 关联

**字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `pid` | int | 进程 ID |
| `ppid` | int | 父进程 ID |
| `agent_id` | string | 归属 Agent |
| `executable` | string | 可执行文件名 |
| `terminated` | bool | 是否已终止 |
| `children` | list[int] | 子进程 PID 列表 |

## 四、输出数据

### 4.1 审计日志（AuditEntry → JSONL）

- **来源**：`AuditLogger.log_event()`
- **格式**：JSONL（每行一个 JSON 对象）
- **存储路径**：`output/audit/audit_{scenario_id}_{timestamp}.jsonl`
- **用途**：完整记录每个事件的处理链路，事后审计、统计、回放

**AuditEntry 字段**（每行 JSON）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `event_id` | string | 事件 ID |
| `agent_id` | string | Agent ID |
| `event_type` | string | 事件类型 |
| `timestamp_ns` | int | 纳秒时间戳 |
| `pid` | int | 进程 ID |
| `description` | string | 事件描述 |
| `command_string` | string | 完整命令（exec） |
| `file_path` | string | 文件路径（file_open） |
| `remote_addr` | string | 远程地址（net_conn） |
| `matched_rules` | list[str] | 命中规则 ID 列表 |
| `highest_rule_action` | string | 最高优先级规则的处置动作 |
| `risk_score` | float | 综合风险评分 (0.0-1.0) |
| `risk_level` | string | 风险等级 (LOW/MEDIUM/HIGH/CRITICAL) |
| `dimension_scores` | dict[str, float] | 四维评分明细 |
| `decision_action` | string | 研判决策 (ALLOW/ALERT/BLOCK) |
| `decision_tier` | string | 处置等级 (TIER1/TIER2/TIER3) |
| `decision_reason` | string | 决策原因 |
| `blocked` | bool | 是否实际阻断 |
| `blocking_tier` | string | 实际执行等级 |
| `blocking_details` | string | 阻断详情 |
| `cmd_id` | string | 反向管道指令 ID |
| `processing_time_ms` | float | 处理耗时（毫秒） |

### 4.2 风险分析报告（Markdown）

- **来源**：`ReportExporter.export_scenario_report()`
- **格式**：Markdown（GitHub Flavored）
- **存储路径**：`output/reports/risk_report_{scenario_id}_{timestamp}.md`
- **用途**：人类可读的风险分析报告，包含概览、风险分布、阻断明细、规则命中、时间线

**报告结构**：

| 章节 | 内容 |
|------|------|
| 1. 概览 | 场景描述、预期结果、总事件数、放行/告警/阻断统计 |
| 2. 风险等级分布 | LOW/MEDIUM/HIGH/CRITICAL 表格 + 柱状图 |
| 3. 阻断/升级事件明细 | 阻断事件表格（事件ID、Agent、类型、评分、决策、执行等级） |
| 4. 规则命中统计 | 规则ID 与命中次数表 |
| 5. Agent 行为摘要 | 各 Agent 的放行/告警/阻断/风险分统计 |
| 6. 跨 Agent 关联分析 | 跨 Agent 关联边（如有） |
| 7. 事件处理时间线 | 文本时间线（[X] BLOCK / [ ] PASS） |

---

### 4.3 链式结构化报告（JSON）

- **来源**：`ChainReportBuilder.save_json()`
- **格式**：JSON（结构化因果链报告）
- **存储路径**：`output/audit/chain_report_{report_id}.json`
- **用途**：当触发阻断时生成，包含完整的因果链分析、影响评估和处置建议

**ChainStructuredReport 字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `report_id` | string | 报告编号，如 `RPT-20260730-001` |
| `timestamp_ns` | int | 触发时间戳 |
| `severity` | string | 严重程度 |
| `affected_agents` | list[str] | 涉及 Agent |
| `cause_chain` | list[CauseStep] | 因果链步骤 |
| `risk_assessment` | RiskAssessment | 风险评估详情 |
| `decision` | Decision | 研判决策 |
| `impact` | ImpactAssessment | 影响评估 |
| `recommended_action` | string | 推荐处置方案 |
| `alternative_actions` | list[str] | 备选方案 |

**CauseStep 字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `step_id` | int | 步骤序号 |
| `event_type` | string | 事件类型 |
| `description` | string | 步骤描述 |
| `actor` | string | 执行者 (agent_id) |
| `pid` | int | 进程 ID |
| `risk_contribution` | float | 该步骤对总风险的贡献值 |
| `causal_link` | string | 与下一步的因果关系说明 |
| `evidence` | dict | 证据数据 |

**ImpactAssessment 字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `impact_type` | string | 影响类型：`data_leak` / `system_damage` / `privilege_escalation` / `suspicious_behavior` |
| `impact_scope` | string | 影响范围：`single_agent` / `multi_agent` / `system_wide` |
| `confidence` | float | 判定置信度 (0.0-1.0) |
| `affected_resources` | list[str] | 受影响资源（文件路径、网络地址） |

### 4.6 全场景汇总报告（Markdown）

- **来源**：`ReportExporter.export_all_summary()`
- **格式**：Markdown
- **存储路径**：`output/reports/summary_all_{timestamp}.md`
- **用途**：一次运行所有场景后的汇总统计
