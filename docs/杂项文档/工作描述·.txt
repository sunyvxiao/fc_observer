模块 1：Fangcun Observer 深度拆解
产品基础信息梳理
产品定义、核心定位：区别于插件 / 文本防火墙，OS 层运行时安全基础设施
五大核心能力：无障碍接入、无感知 Runtime 观测、实时主动阻断、全链路审计追责、本地自进化防御
技术原理拆解
无感知采集逻辑：OS 层捕获 side effect，0 业务代码修改，跨所有 Agent 框架
可监控行为范围：系统命令、文件读写、网络连接
实时阻断流程：风险评分→毫秒研判→高危操作执行前拦截，分级处置（放行 / 警告 / 阻断）
审计链路：多 Agent 行为图谱、时间线、风险定位、完整证据链
自进化闭环：Trace 沉淀→数据挖掘→策略生成→上线验证
四大应用场景逐项拆解
AI Coding Agent（研发环境防护）
业务自动化 Agent（生产业务权限管控）
Multi Agent 多智能体协作系统（串谋、跨 Agent 越权检测）
Agent 合规审计（监管取证、完整行为留存）
梳理产品差异化卖点：数据本地不上云、内核级感知、消除 Agent 伪装欺骗空间
